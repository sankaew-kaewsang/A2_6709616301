How I Built It

I created this website using HTML, CSS, and Bootstrap. HTML was used to structure the content, CSS was used to style it, and Bootstrap made the layout responsive on different screen sizes.

Workflow

  1. Plan each change as a GitHub Issue.
  2. Commit the work on the main branch, referencing the issue number.
  3. Publish the result with GitHub Pages.

Through this project, I learned how to create a basic website from scratch. I also learned how HTML, CSS, and Bootstrap work together to create a responsive webpage that works on phones, tablets, and computers.
